# Aplicación de Conciliación Bancaria - Ejecutable

## Información del Ejecutable

El archivo `ConciliacionBancaria.exe` es una versión empaquetada de la aplicación de Conciliación Bancaria que incluye todas las dependencias necesarias para su ejecución. Esto significa que no es necesario instalar Python ni ninguna biblioteca adicional para usarla.

## Cómo Usar el Ejecutable

1. Extraiga todos los archivos del archivo comprimido (si lo recibió en formato ZIP).
2. Haga doble clic en el archivo `ConciliacionBancaria.exe` para iniciar la aplicación.
3. Seleccione el banco para el cual desea realizar la conciliación (actualmente solo está implementada la conciliación para Itaú).
4. Siga las instrucciones que aparecen en la aplicación para completar el proceso de conciliación.

## Notas Importantes

- La primera vez que ejecute la aplicación, Windows puede mostrar una advertencia de seguridad. Esto es normal para aplicaciones descargadas de Internet. Puede hacer clic en "Más información" y luego en "Ejecutar de todos modos" para continuar.
- Todos los recursos y archivos necesarios están incluidos dentro del ejecutable.
- No mueva o elimine el archivo ejecutable de su ubicación original si hay archivos de datos que debe leer desde una ruta relativa.

## Requisitos del Sistema

- Sistema operativo: Windows 10/11
- Requisitos mínimos:
  - 4 GB de RAM
  - 100 MB de espacio libre en disco
  - Resolución de pantalla mínima: 1280 x 720 píxeles

## Solución de Problemas

Si experimenta problemas al ejecutar la aplicación:

1. **La aplicación no se inicia**: Asegúrese de tener los permisos necesarios para ejecutar aplicaciones en su sistema.
2. **Imágenes o recursos no visibles**: Si la aplicación muestra errores relacionados con recursos faltantes, asegúrese de que no ha modificado la estructura de archivos original.
3. **Errores durante la ejecución**: Tome una captura de pantalla del error y contacte al soporte técnico.
